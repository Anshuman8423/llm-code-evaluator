# Enterprise LLM Code Evaluation & Benchmark Suite

An automated, containerized benchmarking engine designed to evaluate, test, and score code generated by Large Language Models (LLMs). The suite validates syntax integrity, logical correctness, execution safety, and adherence to time/space complexity constraints across multiple programming languages.

---

## Key Features

- **Automated Test Harness:** Executes generated code against custom boundary tests and edge-case suites in an isolated sandbox.
- **AST Static Analysis:** Employs Abstract Syntax Tree (AST) parsing to detect runtime anti-patterns, recursive depth risks, and syntax bugs before execution.
- **Benchmarking & Scoring:** Generates granular evaluation metrics comparing model outputs on correctness, hallucination rate, and execution latency.
- **Resource Constraints:** Enforces strict execution timeouts and memory caps to neutralize infinite loops and resource exhaustion attacks.
